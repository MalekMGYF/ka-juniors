# ملفات استبدال K.A Juniors — مافيوسو والمدارس

هذه الحزمة تحتوي على **الملفات التي تغيّرت فقط** فوق نسخة `ka-juniors-main.zip` التي أرسلتها، وليست نسخة الموقع كاملة.

## التشغيل المطلوب في Supabase

افتح مشروع Supabase الصحيح، ثم ادخل إلى **SQL Editor** والصق محتوى الملف `supabase-migration-mafioso.sql` كاملًا وشغّله مرة واحدة. ينشئ ذلك جداول القضايا، الشخصيات، الأدلة، الرومات، الشات، التصويت، وBucket باسم `mafioso-media` لفويس أوفر نهاية القضية.

> يجب تشغيل SQL قبل الدخول إلى مافيوسو أو فتح تبويب **قضايا مافيوسو** من الأدمن.

## بعد استبدال الملفات

شغّل الفحص المحلي إن أمكن:

```bash
pnpm exec tsc --noEmit
pnpm run build
```

تم تنفيذ هذين الفحصين بنجاح قبل تجهيز الحزمة.

## إدارة القضايا

من **لوحة الأدمن → قضايا مافيوسو** يمكنك إضافة وتعديل وحذف القضايا. كل قضية تتطلب خمسة أدوار بالضبط، منها اثنان مافيوسو وثلاثة بريئين، وأربعة أدلة. يمكن إضافة فويس أوفر اختياري بصيغ MP3 أو M4A أو WAV أو OGG حتى 5MB؛ يظهر بعد انتهاء القضية فقط.

## قواعد مافيوسو المنفذة

اللعبة تبدأ بخمسة لاعبين بالضبط، وتوزّع البطاقات عشوائيًا لكل روم. لكل قضية أربع جولات أدلة، تليها مناقشة وشات نصي وتصويت واحد لكل لاعب مؤهل. اللاعب المستبعد يصبح متفرجًا ولا يكتب في الشات، والمافيوسو المستبعد لا يصوّت في جولة الحسم. إذا بقي لاعبان، يسمح للبريئين المستبعدين بالتصويت في الحسم الأخير، بينما عدم خروج مافيوسو في الحسم يعني فوز المافيوسو.
